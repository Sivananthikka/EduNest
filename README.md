# 🎓 EduNest - Online Learning Platform

EduNest is a frontend-based online learning platform designed to provide
students with an easy and user-friendly environment to explore courses,
learn new skills, and manage their learning activities.

## 📌 About the Project

EduNest is developed as a frontend web development project using
HTML, CSS, and JavaScript.

The platform provides features such as course browsing, course details,
user registration and login, wishlist management, learning dashboard,
profile management, instructor information, and certificates.

## ✨ Features

- 🏠 Attractive homepage
- 📚 Browse available courses
- 🔍 Course search functionality
- 📖 Course details page
- 👨‍🏫 Instructor section
- 🔐 User login and registration
- 👤 User profile
- ❤️ Wishlist functionality
- 🎓 My Learning section
- 📜 Certificate page
- 📩 Contact form
- ❓ FAQ section
- 📱 Responsive design
- 💾 LocalStorage-based data handling

## 🛠️ Technologies Used

## 🚀 How to Run

### Option 1: Using VS Code Live Server

1. Clone the repository:

```bash
git clone https://github.com/Sivananthikka/EduNest.git
```

2. Open the project folder in VS Code.

3. Install the **Live Server** extension in VS Code.

4. Right-click on `index.html`.

5. Select **Open with Live Server**.

6. The EduNest website will open in your browser.

### Option 2: Open Directly

You can also open `index.html` directly in a web browser.
